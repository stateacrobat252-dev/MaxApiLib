# 🤖 Полная инструкция: Как написать своего первого бота на MaxApiLib

> **Цель:** Сделать так, чтобы даже человек, никогда не писавший код, мог запустить своего бота за 15 минут.
> **Принцип:** «Не думай о сложном, просто пиши то, что хочешь, чтобы бот сделал».

---

## 📋 Шаг 0: Подготовка (5 минут)

Прежде чем писать код, нужно получить «ключ» от Telegram и установить инструменты.

### 1. Получение токена (ключа доступа)
Бот не сможет работать без специального пароля — **токена**.
1. Откройте Telegram и найдите официального бота **@BotFather** (у него синяя галочка).
2. Напишите ему команду `/newbot`.
3. Он попросит придумать имя боту (например: `Мой Супер Бот`). Это то, что видят пользователи.
4. Затем он попросит придумать **юзернейм** (ссылку). Он должен заканчиваться на `bot` (например: `SuperCoolTestBot`).
5. Если всё успешно, BotFather пришлет длинное сообщение с текстом вида:
   `Use this token to access the HTTP API: 123456789:AAH...`
6. **Скопируйте этот токен.** Никогда не показывайте его никому!

### 2. Установка Python
Если у вас его нет:
- Зайдите на [python.org](https://www.python.org/downloads/) и скачайте последнюю версию.
- При установке **обязательно** поставьте галочку ✅ "Add Python to PATH".

### 3. Установка библиотеки
Откройте терминал (командную строку) и введите одну команду:
```bash
pip install maxapilib
```
*(Если вы разрабатываете локально и библиотека еще не в PyPI, используйте `pip install -e .` из папки проекта)*

## 🚀 Шаг 1: Ваш первый бот (Эхо-бот)

Создайте файл `bot.py` и вставьте туда этот код. Просто скопируйте и замените `'ВАШ_ТОКЕН'` на тот, что дал BotFather.

```python
from maxapilib import Bot

# 1. Создаем бота
bot = Bot(token='ВАШ_ТОКЕН')

# 2. Говорим боту, что делать, когда ему пишут "/start"
@bot.on_message('/start')
def start_handler(message):
    # Отправляем приветствие с кнопкой
    bot.send_message(
        chat_id=message.chat.id,
        text="Привет! Я твой первый бот. Нажми кнопку ниже!",
        keyboard=[["👋 Помахать"]]  # Кнопка создается просто списком текста
    )

# 3. Говорим боту, что делать на любое другое сообщение (эхо)
@bot.on_message()  # Без аргумента ловит ВСЁ остальное
def echo_handler(message):
    bot.send_message(
        chat_id=message.chat.id,
        text=f"Ты написал: {message.text}"
    )

# 4. Запускаем!
if __name__ == '__main__':
    print("Бот запущен... (нажми Ctrl+C чтобы остановить)")
    bot.run_polling()
```

**Как запустить:**
В терминале напишите: `python bot.py`
Зайдите в своего бота в Telegram, нажмите `/start` и увидите магию.

## 🧠 Шаг 2: Магия состояний (FSM) — Бот-анкета

Иногда нужно запомнить, что пользователь ответил на предыдущий вопрос. Для этого есть **Состояния (States)**.
Представьте, что бот надевает разные шляпы: «Шляпа ожидания имени», «Шляпа ожидания возраста».

```python
from maxapilib import Bot, StateManager

bot = Bot(token='ВАШ_ТОКЕН')
states = StateManager()  # Включаем менеджер состояний

# Объявляем названия наших состояний
STATE_WAIT_NAME = "wait_name"
STATE_WAIT_AGE = "wait_age"

@bot.on_message('/start')
def start(message):
    states.set_state(message.chat.id, STATE_WAIT_NAME) # Надеваем шляпу "Ждем имя"
    bot.send_message(message.chat.id, "Как тебя зовут?")

# Ловим сообщение ТОЛЬКО если у пользователя состояние STATE_WAIT_NAME
@bot.on_state(STATE_WAIT_NAME)
def get_name(message):
    name = message.text
    # Сохраняем имя во временную память
    states.set_data(message.chat.id, "user_name", name)
    
    states.set_state(message.chat.id, STATE_WAIT_AGE) # Меняем шляпу на "Ждем возраст"
    bot.send_message(message.chat.id, f"Приятно, {name}! Сколько тебе лет?")

@bot.on_state(STATE_WAIT_AGE)
def get_age(message):
    age = message.text
    name = states.get_data(message.chat.id, "user_name") # Достаем имя
    
    states.reset_state(message.chat.id) # Снимаем все шляпы, анкета готова
    
    bot.send_message(message.chat.id, f"Готово! {name}, тебе {age} лет. Данные сохранены.")
```

**Почему это просто?**
- Вам не нужно создавать базы данных.
- Вы просто говорите: «Если пользователь в состоянии X, сделай Y».

## ⏰ Шаг 3: Таймеры и отложенные сообщения

Бот умеет ждать и напоминать.

```python
@bot.on_message('/remind')
def remind_me(message):
    # Отправить сообщение через 10 секунд
    bot.later(
        delay=10, 
        func=lambda: bot.send_message(message.chat.id, "Прошло 10 секунд! Ку-ку!")
    )

@bot.on_message('/spam')
def start_spam(message):
    # Отправлять "Тук-тук" каждые 5 секунд бесконечно
    bot.every(
        interval=5,
        func=lambda: bot.send_message(message.chat.id, "Тук-тук"),
        task_id="my_timer" # Имя задачи, чтобы потом можно было остановить
    )
    bot.send_message(message.chat.id, "Я буду стучать каждые 5 секунд!")

@bot.on_message('/stop')
def stop_spam(message):
    bot.stop_task("my_timer")
    bot.send_message(message.chat.id, "Тишина...")
```

## ⌨️ Шаг 4: Красивые кнопки (без боли)

Забудьте про сложные JSON. Кнопки создаются как обычный список списков.

```python
@bot.on_message('/menu')
def show_menu(message):
    # Одна кнопка в ряд:
    row1 = ["🍕 Пицца", "🍔 Бургер"]
    # Вторая кнопка в ряд:
    row2 = ["🥗 Салат"]
    
    # Собираем клавиатуру
    my_keyboard = [row1, row2]
    
    bot.send_message(
        message.chat.id,
        "Что будешь заказывать?",
        keyboard=my_keyboard
    )

# Реакция на нажатие кнопки
@bot.on_message("🍕 Пицца")
def order_pizza(message):
    bot.send_message(message.chat.id, "Отличный выбор! Пепперони или Маргарита?")
```

## 🎣 Шаг 5: Режим Вебхуков (Для продвинутых, но всё ещё простых)

Когда бот вырастет и его нужно будет повесить на сервер, используйте вебхуки вместо опроса (polling).

1. Вам нужен сервер с белым IP или туннель (например, ngrok).
2. Код меняется минимально:

```python
# Вместо bot.run_polling() используем:
if __name__ == '__main__':
    # Укажите URL вашего сервера и порт
    bot.run_webhook(
        webhook_url="https://my-server.com/webhook",
        listen_host="0.0.0.0",
        port=8080
    )
```
*Библиотека сама поднимет сервер и зарегистрирует вебхук в Telegram.*

## 🛠 Частые ошибки новичков (и как их избежать)

1. **Бот не отвечает:**
   - Проверьте, запущен ли скрипт (`python bot.py`).
   - Проверьте токен (нет ли лишних пробелов).
   - Посмотрите в консоль — там будут красные буквы с ошибкой.

2. **Бот забывает данные:**
   - Убедитесь, что используете `states.set_state` перед обработкой ответа.
   - Помните: `reset_state` очищает данные пользователя.

3. **Кнопки не нажимаются:**
   - Текст кнопки в коде и текст, который вы отправляете в `on_message`, должны совпадать **до символа**. "Пицца" ≠ "пицца".

## 📚 Что дальше?

Вы освоили базу! Теперь вы можете:
- Добавить логирование: `bot.enable_logging()` (чтобы видеть ошибки в файле).
- Использовать регулярные выражения: `@bot.on_message(r'\d+')` (ловит числа).
- Отправлять фото: `bot.send_photo(chat_id, photo=open('cat.jpg', 'rb'))`.

Библиотека `maxapilib` создана, чтобы вы занимались идеей бота, а не борьбой с кодом. Экспериментируйте!
